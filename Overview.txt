PHASE 4 — STREAM PROCESSING (Apache Flink)
Apache Flink
🎯 Tujuan
Transformasi data real-time.
Prinsip KUNCI
❌ Connector tidak bicara ke Flink
✅ Kafka adalah contract

Yang kamu bangun:
- Flink cluster (standalone dulu)
- Kafka source & sink table
- SQL execution
- Job lifecycle (submit / stop)

Output:
raw topic → Flink → processed topic
